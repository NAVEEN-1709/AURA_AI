# AURA AI

**Artificial Universal Responsive Assistant**

AURA AI is a human-like personal AI assistant built in Python.

## Vision

AURA is designed to behave like a real intelligent assistant instead of a chatbot.

It can:

- Listen
- Understand
- Remember
- Plan
- Learn
- Observe
- Execute tasks
- Assist with coding
- Control the computer safely

## Technology Stack

- Python 3.12
- FastAPI
- PySide6
- SQLite
- ChromaDB
- Whisper
- Edge TTS
- OpenAI
- Ollama
- Playwright
